# 1. OBJECTIF DU MODULE IA

L'objectif du module IA est de rendre AlkNet intelligent.

L'IA doit pouvoir comprendre les besoins des utilisateurs, analyser les données de la plateforme et proposer automatiquement les services, entreprises, professionnels, produits et opportunités les plus pertinents.

L'IA ne doit pas remplacer le backend Django.

Django reste responsable :

* de l'authentification ;
* des permissions ;
* des règles métier ;
* des transactions ;
* des commandes ;
* des réservations ;
* des paiements ;
* de la persistance des données.

Le module IA doit être un service spécialisé qui communique avec Django via des API.

Architecture souhaitée :

React / Flutter
↓
Django REST API
↓
AI Service
↓
AI Models / LLM / Embeddings / Recommendation Engine

PostgreSQL / Vector Database
